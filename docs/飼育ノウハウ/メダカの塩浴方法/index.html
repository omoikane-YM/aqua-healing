メダカの塩浴方法｜初心者でも失敗しないやり方と注意点

メダカの塩浴とは？

塩浴とは、水に食塩を溶かしてメダカの体への負担を軽減し、回復をサポートする治療方法です。

メダカは体液より薄い真水の中で生活しているため、常に体内へ水が入り続けています。

病気や体調不良になると体力を消耗しやすくなりますが、塩を加えて塩分濃度を調整することで浸透圧の負担が軽くなり、回復しやすい環境を作ることができます。

塩浴だけですべての病気が治るわけではありませんが、初期症状や体力回復には非常に効果的な方法です。

塩浴が有効な症状

次のような症状が見られたら、早めに塩浴を試す価値があります。

元気がなく、水底や水面でじっとしている

いつもより餌の食いつきが悪い、餌を食べなくなった

ヒレを閉じて泳いでいる（ヒレをたたんだ状態）

体色が黒ずんだり、色が薄くなった

水換えや輸送後のストレスで元気がない

病気・異常白点病や水カビ病などの初期症状記事を読む →

他の魚につつかれて体力が落ちている

病気治療後の体力回復・養生

特に「餌を食べなくなった」「食いつきが明らかに悪くなった」という変化は、体調不良のサインであることが多く、見逃さないことが大切です。

早い段階で塩浴を開始できれば、メダカへの負担を軽減し、本来持っている回復力をサポートできる可能性が高まります。

※塩浴は万能ではありません。症状が改善しない場合や悪化する場合は、病気に応じた魚病薬での治療へ切り替えることも検討しましょう。

塩浴に必要なもの

カルキを抜いた水

エアレーション

水温計

※精製塩やアクアリウム用の塩がおすすめです。

💡 隔離容器は2L以上がおすすめ

塩浴には2L以上入る容器をおすすめします。

理由は、水量が少なすぎると水質が悪化しやすく、水温も変化しやすいためです。特にメダカはアンモニアなどの有害物質の影響を受けやすく、1L以下の少量飼育では短時間でも水質が悪化することがあります。

また、2L以上あれば塩の計量もしやすく、0.5％の塩分濃度を管理しやすいというメリットもあります。

さらに、容器に余裕があることでエアレーションもしっかり行え、メダカが落ち着いて泳げるスペースも確保できます。

病気の回復にはストレスを減らすことも大切なので、治療用の隔離容器はできるだけ2L以上を目安に準備しておくと安心です。

塩浴に使って良い塩・使ってはいけない塩

塩浴ではどんな塩でも良いわけではありません。

メダカへの負担を減らすためにも、余計な添加物が入っていない塩を選ぶことが大切です。

塩の濃度は0.5％が基本

メダカの塩浴では0.5％（5g/L）が基本です。

計算例

1L → 5g

2L → 10g

5L → 25g

10L → 50g

塩は一度に入れず、水でよく溶かしてから少しずつ加えましょう。

塩浴中のポイント

塩浴中はメダカの様子をよく観察しながら、できるだけストレスを与えない環境を維持しましょう。

エサは基本的に与えない（消化に体力を使うため）

毎日、泳ぎ方や呼吸、食欲などを観察する

水温の急激な変化を避ける

エアレーションを行い、十分な酸素を確保する

水質管理も非常に重要です

塩浴中はフィルターを使用しないことが多いため、水量が少ないほどフンやアンモニアが溜まりやすく、水質が悪化しやすくなります。

2L以上の隔離容器であれば比較的水質は安定しやすいですが、水量が少ない場合は毎日約半分（1/2）の水換えを行うと安心です。

水換えを行う際は、交換する水もあらかじめ0.5％の塩水を作っておき、水温を合わせてから交換しましょう。真水に交換してしまうと塩分濃度が下がり、メダカに負担をかけてしまいます。

また、フンや食べ残しなどの汚れは放置せず、スポイトでこまめに吸い取ることで、水質の悪化を防ぐことができます。

塩浴中は「塩を入れること」だけでなく、きれいな水を維持することがメダカの回復を早める大切なポイントです。

エアレーションはできるだけ使用しましょう

塩浴中はエアレーションを使用することをおすすめします。

0.5％の塩水は真水に比べて酸素がやや溶け込みにくくなります。また、体調を崩したメダカは回復のために酸素を多く必要とするため、酸欠を防ぐことが大切です。

特に次のような場合は、エアレーションを使用した方が安心です。

夏場など水温が高い時期

2匹以上を同時に塩浴する場合

水量が少ない隔離容器で管理する場合

呼吸が速いなど、体力が落ちているメダカを塩浴する場合

エアレーションを使用する際は、水流が強すぎると弱ったメダカの負担になるため、弱め〜中程度のエアー量に調整しましょう。

塩浴期間の目安

塩浴期間は3〜7日程度が目安です。

ただし、日数だけで判断するのではなく、メダカの様子を見ながら終了するタイミングを判断することが大切です。

私が塩浴を終える目安としているのは、次のような状態です。

水槽内を元気に泳ぎ回るようになった

底や水面でじっとする時間が少なくなった

呼吸が落ち着いている

ヒレをしっかり広げて泳いでいる

さらに、餌を1粒だけ与えて反応を見るようにしています。

すぐに餌へ近づき、普段と変わらない勢いで食べるようであれば、体力が回復してきたサインと判断しています。

反対に、

餌に興味を示さない

口に入れても吐き出してしまう

食べた後も元気がない

まだ底でじっとしている時間が長い

このような場合は、まだ回復途中と考え、無理に塩浴を終えず様子を見るようにしています。

真水へ戻す際もゆっくり行う

元気になったからといって、急に真水へ戻すのは避けましょう。

急激な塩分濃度の変化はメダカにとって大きなストレスとなるため、1日に20〜30％ずつ真水へ交換し、2〜3日かけてゆっくり塩分濃度を下げるのがおすすめです。

焦らずメダカの様子を確認しながら進めることで、回復後の体への負担を最小限に抑えることができます。

実際に何度も塩浴を行って感じたこと

私は今まで体調を崩したメダカを何度も塩浴で回復させてきました。

最初の頃は、別容器で0.5％の塩水を作り、それを点滴法で少しずつ隔離容器へ加える方法で塩浴を行っていました。

点滴法は急激な水質変化を防げるため、メダカへの負担が少ない非常に優れた方法です。

しかし実際には、

隔離している飼育水の量

足す塩水の量

最終的に0.5％になる塩の量

これらを毎回計算する必要があり、準備にも時間がかかります。

もちろん、ゆっくり塩分濃度を上げられる点は大きなメリットですが、初心者には少しハードルが高い方法だと感じました。

細かな計算や点滴法の準備が不要になり、治療開始までの時間を大幅に短縮できました。

💡 なぜ塩浴で元気になるの？「浸透圧」をわかりやすく解説

塩浴が効果的と言われる理由は、浸透圧（しんとうあつ）という仕組みにあります。

少し難しく聞こえますが、簡単に言えば

「体の中の水分バランスを保つために使う体力を減らしてあげること」

です。

メダカは淡水魚なので、体の中は外の水より塩分濃度が高くなっています。

そのため普通の真水では、常に体の中へ水が入り込もうとするため、

余分な水を排出する

体内の塩分濃度を一定に保つ

という作業を24時間休まず続けています。

つまり、健康なメダカでも常に体力を使っている状態です。

病気やストレスで弱ったメダカは、この体力の消耗が大きな負担になります。

そこで約0.5％の塩水にすると、水と体液の塩分濃度の差が小さくなります。

すると、

水分調整の負担が軽くなる

体力を回復に回せる

自然治癒力が働きやすくなる

という状態になります。

塩そのものが病気を治すというよりも、

「メダカが本来持っている回復する力を助ける治療法」

と考えると分かりやすいでしょう。

⚠️ 塩浴を行う際の注意点

塩浴は非常に効果的ですが、万能ではありません。

基本濃度は約0.5％を目安にする

急激に塩分濃度を変えない

強い薬との併用は避ける

塩浴中は餌を控えめにする

水温やエアレーションも十分に確保する

また、数日経っても改善しない場合や症状が悪化する場合は、病気に応じた薬浴へ切り替える判断も重要です。
