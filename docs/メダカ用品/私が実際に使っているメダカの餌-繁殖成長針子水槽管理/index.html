商品の特徴

GEX「メダカ元気 彩姫」は、精選されたアメリカミズアブを原料に使用した高栄養タイプのメダカ用フードです。

産卵をサポートするリン脂質や高度不飽和脂肪酸、高たんぱく・カルシウムを配合し、繁殖期の親メダカの健康維持に配慮されています。

また、超ソフト顆粒のため食べやすく、必要に応じてすりつぶして与えることもできます。

実際に使って良かったところ

私は繁殖期になると、この餌をメインに与えています。

以前使用していた餌と比べて食いつきが非常によく、餌を入れるとすぐに集まってきます。

また、この餌を使い始めてから定期的な産卵や継続した産卵につながっていると感じています。

もちろん産卵数は水温や日照時間、水質、個体の状態などさまざまな条件に左右されますが、私の飼育環境では繁殖期のメインフードとして満足しています。

気になったところ

たまに大きめの粒が混ざっていることがあり、吐き出してしまう個体がいます。

頻繁ではありませんが、口の小さい個体には少し食べにくそうな場面がありました。

🐟 稚魚から若魚の成長をサポートする高栄養フード

おすすめポイント

稚魚から若魚（約2.5cmまで）の成長に適した高栄養設計

精選されたアメリカミズアブを配合し、高たんぱく・高脂質で成長をサポート

カルシウムを強化配合

超ソフト顆粒（約0.2～0.4mm）で食べやすい

指で簡単につぶせるため、小さな個体にも与えやすい

便利な計量スプーン付き

商品の特徴

「メダカ元気 彩姫 成長用」は、稚魚から若魚の成長期に必要な栄養を考えて作られたプレミアムフードです。

メーカーでは、精選されたアメリカミズアブを使用し、高たんぱく・高脂質・カルシウム強化の配合により、稚魚から若魚の健やかな成長をサポートするとしています。また、超ソフト顆粒のため、そのまま与えるだけでなく、細かくつぶして与えることもできます。

実際に使って良かったところ

私も針子用の餌から切り替えるタイミングで、この「彩姫 成長用」を使用しています。

粒がやわらかいため、小さめの若魚でも食べやすく、食いつきも良好です。

成長期に必要な栄養をしっかり摂れる印象があり、丈夫に育ってほしい時期のメインフードとして使っています。

また、粒を簡単につぶせるので、まだ口が小さい個体にも与えやすい点が便利です。

気になったところ

与えすぎると食べ残しが出やすく、水質悪化の原因になります。

天然原料を使用しているため、粒の大きさや色に多少ばらつきがありますが、品質には問題ありません。

私は1回で食べ切れる量を1日1〜2回与えるようにしています。
