メダカを飼育していると、

「体に白い点がある」

「ヒレがボロボロになってきた」

「体が赤くなっている」

「白い綿のようなものが付いている」

「鱗が逆立っている」

など、さまざまな異常が見られることがあります。

しかし、メダカの体調不良は必ずしも病気が原因とは限りません。

水質の悪化、酸欠、水温の急変、過密飼育、餌の与えすぎ、寄生虫など、さまざまな原因が考えられます。

この記事では、メダカに起こりやすい代表的な病気について、

症状 → 原因 → 害・危険度 → 対策 → 対応する魚病薬

まで、まとめて解説します。

「うちのメダカは病気かも？」と思ったときの早見表としても使える完全ガイドです。

どんな病気？

病気・異常白点病は、メダカの体表やヒレに白い小さな点が現れる病気です。記事を読む →

白い点が1つ、2つではなく、進行すると多数見られるようになります。

体を水草や底、容器などにこすりつける行動が見られることもあります。

原因

白点虫（Ichthyophthirius multifiliis）という寄生虫が原因です。

害・危険度

初期であれば治療できるケースが多いものの、進行すると体表だけでなくエラにも影響し、呼吸に問題が出る可能性があります。

そのため、白点を見つけた段階で早めに対応することが重要です。

対策

まず飼育環境を確認し、水質が悪化している場合は改善します。

必要に応じて水換えを行い、対応する魚病薬で薬浴します。

水温を上げる方法が紹介されることもありますが、急激な水温変化はメダカの負担になるため注意しましょう。

どんな病気？

病気・異常尾ぐされ病は、主に尾びれや各ヒレが傷んでいく病気です。記事を読む →

初期にはヒレの先端が白く濁ることがあります。

進行するとヒレが溶けるように短くなり、ボロボロになっていきます。

原因

カラムナリス菌（Flavobacterium columnare）による細菌性の病気です。

害・危険度

進行するとヒレが大きく失われ、泳ぎに影響することがあります。

さらに状態が悪化する可能性もあるため、初期段階での対応が重要です。

対策

水質を確認し、必要に応じて水換えを行います。

過密飼育や水質悪化など、細菌が増殖しやすい環境になっていないか確認しましょう。

どんな病気？

体表やヒレなどに、白～灰色の綿毛のようなものが付着します。

卵にも発生することがあり、水カビに覆われた卵は白く見えるようになります。

原因

水カビ類が原因です。

ただし、水カビは健康な魚に突然大量発生するというより、

傷・スレ・細菌感染・寄生虫などによってできた傷

をきっかけに二次的に発生することがあります。

害・危険度

水カビそのものだけでなく、水カビが発生するきっかけとなった傷や病気を放置することが問題です。

卵の場合は、水カビが広がることで周囲の卵にも影響することがあります。

対策

水換えを行い、水質を改善します。

必要に応じて薬浴を行います。

また、

「なぜ水カビが付いたのか？」

を考えることも重要です。

寄生虫や細菌性の病気が隠れていないか確認しましょう。

対策

🪱 病気ではなく「寄生虫」が原因の場合

メダカの異常では、病気だけでなく寄生虫も疑う必要があります。

例えば、

白点虫

トリコディナ

ウオジラミ

イカリムシ

などです。

寄生虫によって、

体をこする・元気がなくなる・ヒレを閉じる・餌を食べなくなる

など、病気とよく似た症状が出ることがあります。

「白いものが付いているから水カビ」と決めつけるのではなく、実際に何が付いているのかを観察することが大切です。

💧 病気の前に「水質」を確認しよう

メダカの体調不良では、病気そのものよりも飼育環境の悪化がきっかけになっている場合があります。

特に確認したいのが、

水質悪化

アンモニアや亜硝酸などが増えると、メダカに大きな負担がかかります。

水が透明だからといって、水質が良好とは限りません。

酸欠

水面で口をパクパクしている場合は、酸素不足の可能性があります。

特に、

高水温

過密飼育

水草が多い環境

水面がほとんど動かない環境

では注意が必要です。

水温の急変

急激な水温変化はメダカの負担になります。

水換えの際も、水温差が大きくならないよう注意しましょう。

飼育ノウハウ👉 メダカの水換え方法はこちら記事を読む →

過密飼育

メダカの数が多すぎると、

水質悪化 → ストレス → 体力低下 → 病気

という流れにつながることがあります。

餌の与えすぎ

食べ残しは水質悪化につながります。

「よく食べるからもっとあげよう」ではなく、短時間で食べ切れる量を基本にしましょう。
